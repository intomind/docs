    Glossary

    TermMeaning
    ADCThe analog-to-digital converter, which turns the electrodes' voltages into numbers. The IntoMind One uses a Texas Instruments ADS1299-4.
    APIThe Python package intomind, for scripts, recordings and analysis.
    CapabilityA feature a device reports that it supports. Software asks a device only for what it reports.
    ChannelOne electrode, measured against the reference. The IntoMind One has four.
    Command CenterThe app for using the device from your computer, in your browser.
    Device timeThe device's own clock, which stamps every sample. Software maps it onto your computer's clock.
    EmbeddingThe 76 numbers the encoder produces for each window. Heads read them.
    EncoderThe neural network on the device that produces embeddings and tokens.
    FilterA high-pass filter removes slow drift, a low-pass filter removes fast content, and a notch filter removes a narrow band, such as the mains frequency.
    GainHow much the ADC amplifies the signal before converting it, from 1 to 24.
    GapA place in a stream where samples were lost. The stream says where and how many.
    GeneratorThe small model on the device that produces the synthetic signal.
    HeadA small set of weights that turns an embedding into up to 32 numbers. You train heads and run them on the device.
    Lead-off detectionA check that shows which electrodes touch the skin, by passing a very small current through them.
    Mains frequencyThe frequency of household electricity, 50 or 60 Hz, which every EEG picks up.
    PairingThe first connection between a computer and the device, which sets up the encryption for every later one.
    Processing chainThe filters the device applies to its signal before streaming it. Every stream states its chain.
    ProtocolThe contract for the Bluetooth messages between an IntoMind device and any software.
    Reconstruction headThe open head that turns tokens back into signal.
    ReferenceThe electrode every channel is measured against.
    SampleOne measurement of every channel at one moment.
    Sample rateHow many samples the device takes per second: 250, 500 or 1000.
    SDKThe Rust crates and the JavaScript package for building your own applications.
    SlotOne of four places on the device for a head you upload.
    Synthetic signalA signal the device generates in place of its electrodes, marked as generated wherever it goes.
    TokenOne of the 80 vectors the encoder produces for each window, one per channel for each fifth of a second.
    Web BluetoothThe browser feature that lets a web page connect to a Bluetooth device.
    WindowFour seconds of signal, the span the model describes at once.
    µVA microvolt, one millionth of a volt. EEG is measured in microvolts.
